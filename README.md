Ejercicio 2 — Estructurando una ventana con BorderLayout
BorderLayout es el layout más adecuado para definir la estructura general de una ventana. En este ejercicio vas a practicar su uso organizando una ventana en tres zonas claramente diferenciadas.

Construí una ventana utilizando BorderLayout que quede organizada de la siguiente manera:

Zona NORTH: un panel con una etiqueta que diga "Sistema de Turnos Médicos"
Zona CENTER: un panel vacío que represente el área principal de contenido (podés agregarle un color de fondo para que sea visible)
Zona SOUTH: un panel con tres botones: "Nuevo turno", "Ver turnos" y "Salir"
Una vez construida la ventana, redimensionála y observá cómo se comporta cada zona. En un comentario dentro del código, explicá qué zona se expande al agrandar la ventana y por qué creés que sucede eso.

💡 Tip: para agregarle color de fondo a un panel usá el método setBackground(Color.LIGHT_GRAY) o cualquier otro color de tu preferencia.
